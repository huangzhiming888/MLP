# MLP — NEURAL/CONSOLE

一个单文件的神经网络可视化控制台：用纯前端的 2-2-1 MLP 实时训练 **XOR**，并把参数被"学会"的过程画出来。

## 看点

- **决策边界**：输入平面上 4 个 XOR 点，背景色即网络当前输出，训练时能看见边界从一条直线慢慢弯折成两片。
- **权重与梯度**：每个连接线的粗细、颜色随权重与梯度实时变化，隐藏层两个神经元各自学到的"半平面"一眼可见。
- **隐藏层特征空间**：2 个隐藏单元的激活值构成二维散点，XOR 从线性不可分变成可分的过程就是这个空间的形变。
- **训练控制**：可调学习率、激活函数、初始化、单步/连续训练，观察梯度消失与饱和。
- 深色/浅色双主题，纯 HTML + CSS + Canvas，无任何外部依赖，双击即可运行。
